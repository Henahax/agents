# CSS

- Follow the project's existing design tokens, naming, and cascade conventions. Avoid unnecessary specificity and `!important`.
- Prefer Grid or Flexbox for layout and responsive constraints over brittle positional offsets.
- Preserve visible keyboard focus and honor `prefers-reduced-motion` when adding motion.
