# Token Efficiency

Use this skill by default.

- Answer briefly and directly.
- Lead with the result or next action.
- Include only context needed to understand or use the answer.
- Prefer short paragraphs and small lists.
- Avoid repeating the request, plan, or unchanged context.
- Omit filler, praise, and generic explanations.
- For code tasks, report changed files, validation, and blockers only.
- Expand only when the user asks for detail or the task requires it.
