# Documentation Rules

- Write agent Markdown and documentation in English.
- Keep shared instructions concise and precise.
- Before finishing instruction or documentation edits, check related files for duplicate or conflicting guidance. Keep one canonical rule and link to it where needed.
- Write only guidance that changes an agent's decisions, actions, or necessary context. Remove generic advice and repeated content already covered by linked references or templates.
- Keep each fact in one canonical place; link instead of restating it.
- Before finishing, remove any sentence whose deletion would not change a decision, action, or necessary context.
