# Project Setup

Use this template to connect a project to the central `agents` repository.

## 1. Add `AGENTS.md`

Copy the template into the project root.

Fill in:

* Project description
* Technologies
* Project-specific instructions
* Relevant skills

## 2. Connect to `agents`

Prefer the local clone:

```text
../agents
```

GitHub can be used as a fallback:

```text
https://github.com/henahax/agents
```

## Principles

* Keep project `AGENTS.md` short.
* Keep reusable knowledge in `agents/skills/`.
* Don't copy shared skills into projects.
* Project-specific rules belong in the project's `AGENTS.md`.
